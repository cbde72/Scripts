Test Procedure

Place the device under test (DUT) inside the test chamber, ensuring specimen spacing ≥10 cm, and distance from the temperature chamber ≥10 cm; assemble the test plan according to the test arrangement.

The chamber temperature shall be set according to the following parameters for a total of 30 cycles.

Time (min)060150210300410480
Temperature (℃)20TminpTminop20TmaxopTmaxop20

Once the DUT temperature stabilizes at Tminop, the DUT is powered on for a brief period to operate in Mode 3.2 to verify normal functionality. Immediately after verification, it enters sleep mode (Mode 3.1), and is powered on again between the 210th and 410th minute.

Upon test completion, allow the specimen to naturally recover to room temperature, and then conduct a function inspection.

Test Class and Acceptance Criteria

During testing, the functional status of components complies with Function Grade Class A.

After testing, the specimen must satisfy visual inspection criteria; the appearance shall exhibit no significant damage, and no abnormal noise shall be heard from components after shaking.

Configuration and Time Step

env_config.json contains all eight tests. Move a parameter key and its value between visible and unvisible to control whether its GUI input is shown. Both sections remain active. Load Configuration applies visibility changes. Save Current Test updates only the selected test section.

CSV Time Step [s] is the regular sampling interval for exported data. Phase boundaries are added exactly. Changing it does not change test duration. Tracker Step [s] controls only mouse snapping. Time Unit controls the X-axis display with automatic conversion.
