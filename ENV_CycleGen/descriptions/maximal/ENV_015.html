Temperature Gradient Test

Reference duration: 28.5 h. Source: 2.ENV_Test_Plan_Cp_r00v05(1).docx.

Generator Interpretation and User Overrides

  • The initial 25 °C dwell is ALWAYS included, as explicitly requested. It is not a configurable parameter. With the default values: 49 dwell points and 28.5 h total.
  • At each point: 25 min Mode 3.1, 1 min Mode 3.2 at Umax, 3 min Mode 3.1, 1 min Mode 3.2 at Umin. Voltage conditions are in Phase; this test has no separate voltage output channel.
  • Ramp Mode 3.1 is a declared implementation assumption; default RH is 60%.

Test Procedure

Place the device under test (DUT) inside the test chamber, ensuring specimen spacing ≥10 cm, and distance from the temperature chamber ≥10 cm; assemble the test plan according to the test arrangement.

Turn on the test chamber and set parameters: Tminop; Tmaxop; Starting from 25℃, temperature changes in 5℃ increments (temperature change rate 1℃/min, each increment held for 30 minutes), gradually cooling to Tminop, then gradually heating to Tmaxop, followed by gradual cooling back to 25℃, completing one cycle;

Each temperature gradient point shall be executed according to the following operating modes and durations

a) Mode 3.1 held for 25 Minutes duration

b) Mode 3.2 operating at Umax for 1 Minute duration

c) Mode 3.1 held for 3 Minutes duration

d) Mode 3.2 operating at Umin for 1 Minute duration

Upon test completion, allow the specimen to naturally recover to room temperature, and then conduct a function inspection.

Test Class and Acceptance Criteria

All function inspection results comply with Class A standards.

After testing, the specimen must satisfy visual inspection criteria; the appearance shall exhibit no significant damage, and no abnormal noise shall be heard from components after shaking.

Configuration and Time Step
