Damp Heat Cycle 3 – Condensation Test

Reference duration: 25 h. Source: 2.ENV_Test_Plan_Cp_r00v05(1).docx.

Generator Interpretation and User Overrides

  • The CURRENT procedure and user instruction require ONE function check per cycle: switch from Mode 3.1 to Mode 3.2 as soon as Tmax is reached. Return to 3.1 after the configured check duration.
  • The check duration is not numerically specified. The configurable 1-minute default is an assumption. The old second check at the end of hot dwell has been removed.
  • Reference timing: 45 min room hold, 120 min rise, 45 min hot dwell, 90 min fall: 5 h per cycle, 25 h for 5 cycles.
  • Rise/hot RH is 97.5% as a nominal choice within 95–100%; hot-dwell use is a recipe assumption. Falling RH is 80%. Room hold uses the default 60% where no specific setpoint is given.

Test Procedure

Place the device under test (DUT) inside the test chamber, ensuring specimen spacing ≥10 cm, and distance from the temperature chamber ≥10 cm; assemble the test plan according to the test arrangement.

Activate the Constant Temperature and Humidity Test Chamber and set the following parameters: high temperature at 80℃, low temperature at 23±5℃; humidity ranging from 95% to 100% RH during the temperature rise interval from 23℃ to 80℃; humidity maintained at 80% RH during the cooling phase from 80℃ to 23℃.

At the maximum cycle temperature (80℃), switch the DUT from 3.1 mode to 3.2 operating mode and perform functional testing. Functional testing will be conducted once per cycle. Each cycle lasts 5 hours, with a total of five cycles performed.

Upon test completion, allow the specimen to naturally recover to room temperature, and then conduct a function inspection.

Test Class and Acceptance Criteria

The DUT must comply with Class A functional status requirements both prior to and following testing.

After testing, the specimen must satisfy visual inspection criteria; the appearance shall exhibit no significant damage, and no abnormal noise shall be heard from components after shaking.

Configuration and Time Step

env_config.json contains all eight tests. Move a parameter key and its value between visible and unvisible to control whether its GUI input is shown. Both sections remain active. Load Configuration applies visibility changes. Save Current Test updates only the selected test section.

CSV Time Step [s] is the regular sampling interval for exported data. Phase boundaries are added exactly. Changing it does not change test duration. Tracker Step [s] controls only mouse snapping. Time Unit controls the X-axis display with automatic conversion.
