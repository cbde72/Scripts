Five-Point Function/Performance Test

Reference duration: 5.38333 h. Source: 2.ENV_Test_Plan_Cp_r00v05(1).docx.

Generator Interpretation and User Overrides

  • User-selected 48-V component: UN = 48 V, Umin = 36 V, Umax = 52 V; UA = 48 V and UB = 48 V follow Section 2.1. UN = 48 V is the nominal-system selection.
  • Mode 3.1 is Stand-by at UA. Temperature transitions and preconditioning use UA, independently of UN. The five active checks use UN, Umax, Umin, Umax, Umin.
  • 30 min preconditioning at each temperature and 10 min activation at each test point follow Chapter 6. The 1 °C/min transition rate and Troom = 23 °C are configurable assumptions.
  • Default duration is 323 min; optional final recovery adds 57 min. Default RH is 60%, not a requirement in Chapter 6.

Test Procedure

Place the device under test (DUT) inside the test chamber, ensuring specimen spacing ≥10 cm, and distance from the temperature chamber ≥10 cm; assemble the test plan according to the test setup.

Set the temperature chamber to Troom; once stabilized, maintain this condition for 30 minutes.

Apply a power supply voltage of UN to the specimen for function inspection.

Apply the activation profile to the specimen for 10 min

Set the temperature chamber to Tmin

Once stabilized, maintain this condition for 30 minutes.

Apply a power supply voltage of Umax to the specimen for function inspection.

Apply the activation profile to the specimen for 10 min

Apply a power supply voltage of Umin to the specimen for function inspection.

Apply the activation profile to the specimen for 10 min

Repeat steps 6-10, setting temperature to Tmax

Test Class and Acceptance Criteria

All function check results meet the functional status Class A, with no issues identified during visual inspection.

Configuration and Time Step

env_config.json contains all eight tests. Move a parameter key and its value between visible and unvisible to control whether its GUI input is shown. Both sections remain active. Load Configuration applies visibility changes. Save Current Test updates only the selected test section.

CSV Time Step [s] is the regular sampling interval for exported data. Phase boundaries are added exactly. Changing it does not change test duration. Tracker Step [s] controls only mouse snapping. Time Unit controls the X-axis display with automatic conversion.

Only the current uploaded Word file and the explicitly requested user overrides are used. External master specifications were not read or used. References printed inside the source chapter are not independent verification of those standards.
